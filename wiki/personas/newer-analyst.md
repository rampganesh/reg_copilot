# Persona: Newer analyst

Inferred primarily from experienced analysts' accounts of the newer-analyst state (both were newer once; no direct newer-analyst interview yet — flagged as a discovery gap).

## Job to be done
Learn how to investigate regulatory questions correctly while still producing reliable answers for the team.

## Behaviour (as reported)
- Relies heavily on colleagues, previous examples and knowing which documents contain particular types of information (source: 2025_06_17_interview_analyst1exp.md, L113; source: 2025_06_18_interview_analyst2prov.md, L114)
- Needs help understanding **why one source should be trusted over another** — experienced analysts recognise this from experience, newer ones must learn it (source: 2025_06_18_interview_analyst2prov.md, L112)
- Follows the taught research path: which source types to search, distinguishing authoritative from supporting material, checking dates/status, tracing references, documenting evidence (source: 2025_06_17_interview_analyst1exp.md, L101-109; source: 2025_06_18_interview_analyst2prov.md, L104-110)
- Spends considerably longer finding the same answers (source: 2025_05_24_meeting_kickoff.md, L23)

## Value proposition (distinct from the experienced persona)
- Learning support: a system that teaches the research path (why sources are trusted, how validation works) — the SME's caution: a system for experienced analysts "may need to behave differently from one designed to teach newer analysts how to investigate" (source: 2025_05_24_meeting_kickoff.md, L81)
- Reducing time-to-competence and dependence on colleague availability

## Open questions
- No direct interview yet — all evidence is second-hand. A newer-analyst interview would test this page's behavioural claims directly (candidate for next discovery round).
